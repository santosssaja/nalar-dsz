# 24. Kurikulum

Kurikulum Nalar dirancang sebagai peta pengetahuan yang saling terhubung, bukan sekadar daftar mata pelajaran.

## Struktur Utama

**Domain → Subdomain → Module → Learning Path → Concept → Learning Steps**

Kurikulum dapat dikembangkan secara bertahap. Tidak semua topik harus tersedia sejak versi awal, tetapi struktur besarnya sudah disiapkan agar Nalar dapat berkembang tanpa mengubah fondasi sistem.

## 24.5 Cross-Link Antarbidang

Salah satu karakteristik utama kurikulum Nalar adalah bahwa konsep tidak dianggap berdiri sendiri.

Satu konsep dapat menjadi dasar bagi banyak bidang lain.

Contoh:

- Kalkulus → Turunan → Laju Perubahan → Kecepatan → Kinematika → Fisika
- Kalkulus → Integral → Luas di bawah kurva → Akumulasi → Probabilitas → Statistika
- Aljabar Linear → Vektor → Ruang Vektor → Transformasi Linear → Computer Graphics → Machine Learning
- Probabilitas → Conditional Probability → Bayes → Inferensi → Machine Learning → AI
- Kimia → Struktur Atom → Elektron → Ikatan Kimia → Molekul → Biokimia → Biologi Sel
- Biologi → DNA → Gen → Ekspresi Gen → Protein → Biokimia → Bioteknologi
- Fisika → Elektromagnetisme → Gelombang Elektromagnetik → Cahaya → Optik → Computer Vision
- Matematika → Kriptografi → Teori Bilangan → Keamanan Informasi → Cybersecurity

## 24.6 Prinsip Penyusunan Kurikulum

Kurikulum Nalar tidak menggunakan struktur linear yang mengharuskan pengguna menyelesaikan seluruh materi secara berurutan.

Setiap konsep memiliki:

- Prasyarat konsep
- Konsep lanjutan
- Hubungan dengan bidang lain
- Tingkat kesulitan
- Learning Path
- Learning Steps
- Latihan
- Eksperimen
- Aplikasi
- Konsep terkait
